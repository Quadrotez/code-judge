# CodeJudge - Платформа для проверки задач по программированию

Современная платформа для хостинга задач по программированию с поддержкой Python и C++, встроенным Markdown-редактором и системой автоматического тестирования.

## 🚀 Технологии

- **Frontend:** React 18, Vite, React Router 6
- **Стилизация:** CSS3 (с поддержкой темной темы)
- **База данных:** Firebase Firestore
- **Авторизация:** Firebase Authentication (Email/Password)
- **Исполнение кода:**
  - **Python:** Pyodide (WebAssembly) в Web Workers
  - **C++:** Wandbox API
- **Рендеринг контента:**
  - **Markdown:** `marked`
  - **LaTeX:** `KaTeX`
  - **Подсветка синтаксиса:** `highlight.js`

## 🎨 Иконки и графика

В проекте используются иконки из набора **Heroicons**.
- **Лицензия:** MIT
- **Источник:** [heroicons.com](https://heroicons.com/)
- Иконки встроены в проект как SVG-компоненты для обеспечения максимальной производительности и независимости от внешних CDN.

## ✨ Основные функции

- **Умный редактор:** Нумерация строк, автодополнение кода (Python/C++), подсветка синтаксиса.
- **Markdown-редактор:** Создание условий задач с поддержкой формул LaTeX и предпросмотром в реальном времени.
- **Система тегов:** Группировка и поиск задач по категориям.
- **Скрытые тесты:** Возможность добавления тестов, которые не видны пользователю, но учитываются при проверке.
- **Безопасность:** Интеграция с Firebase Auth, защита от брутфорса на стороне клиента, изоляция кода в Web Workers.

## 🛠 Установка и запуск

1. Установите зависимости: `npm install`
2. Настройте Firebase в `src/utils/firebaseConfig.js`
3. Запустите в режиме разработки: `npm run dev`
4. Сборка для GitHub Pages: `npm run build`
